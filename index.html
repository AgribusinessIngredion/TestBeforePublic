⚠️ Data notes

    🚀 วิธีนำขึ้น GitHub Pages

    1. สร้าง repository ใหม่ เช่น root-sourcing-dashboard
    2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ ได้แก่ index.html, โฟลเดอร์ data, โฟลเดอร์ tools และ README.md
    3. ไปที่ Settings → Pages แล้วเลือก Branch: main และ Folder: /root
    4. รอ GitHub Pages build เสร็จ แล้วเปิดลิงก์ Dashboard ได้ทันที

    Update data รอบถัดไป

    นำ Excel ชุดใหม่วางไว้ในโฟลเดอร์เดียวกับโปรเจกต์ แล้วรัน:

    python tools/convert_excel_to_json.py

    หรือถ้าไฟล์ Excel อยู่ในโฟลเดอร์อื่น ให้ระบุ path:

    python tools/convert_excel_to_json.py /path/to/excel-folder
